# Arcade-Catalog-MiSTer

Arcade catalog and editorial database for MiSTer FPGA.

This project organizes the installed MiSTer Arcade library into curated views such as:

- By Company
- By Board
- By Genre
- By Year
- Alternatives

The project is designed to work with the standard MiSTer frontend and does not modify official MRAs, RBFs, ROMs or MiSTer.ini.

Metadata and classification are generated from MiSTer Arcade MRAs, public MiSTer databases, MAME metadata and Arcade Catalog editorial rules.

## Repository structure

- `remote/` — databases consumed by the MiSTer script
- `builder/` — tools used to generate and audit metadata
- `.github/workflows/` — automated database generation
